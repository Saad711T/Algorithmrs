# Algorithmrs
Blog about algorithms and data structures , Specially in Data science and Web.

## Goal

The blog focuses on enhancing algorithm skills and reviewing data structures for programmers and data scientists, and is a further extension of the previous [SaadAIBlog](https://saadaiblog.netlify.app/).

## Project structure
- R/Quarto : Front end Built with R language and Quarto library a web static html/css files generator , With simple bootstrap templates.
- CSS : Using to styling website.
- Java : Using to Building algorithms and example , Also used in back end later
- Python : Like Java , For examples and back-end development
